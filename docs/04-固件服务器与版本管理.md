# 功能说明：固件服务器与版本管理

> 相关代码：`src-tauri/src/upgrade.rs`（`normalize_server_url` / `fetch_server_items` / `download_fw` / `ver_is_3seg` / `ver_u32`）

## 1. 是什么

让上位机直接从一个 HTTP 目录拉固件清单、列出可用版本、挑一个下载下来并**先自检再升级**。
免去"人工找包→拷贝→核对"的来回。

## 2. 服务器端怎么摆

只需要一个静态 HTTP 目录（nginx / 对象存储 / 内网文件服务都行）：

```
https://example.com/ota/demo/
├─ manifest.json
├─ demo-v1.3.1.fw
└─ demo-v1.3.0.fw
```

上位机的"地址"栏填**目录**、**manifest.json**、甚至**单个 .fw 的 URL** 都可以：
`normalize_server_url` 会自动补成 manifest 地址。

## 3. 支持的清单格式

### ① 标准写法（推荐）

```json
{
  "firmwares": [
    { "version": "1.3.1", "name": "demo-v1.3.1.fw", "size": 262144,
      "crc32": "9A3C1F08", "payload_crc32": "1122AABB", "board": "demo-bd" }
  ]
}
```

### ② 面板导出的写法

```json
{
  "versions": [
    { "version": "1.3.1", "folder": "v1.3.1",
      "targets": [ { "files": [ { "name": "demo-v1.3.1.fw", "url": "v1.3.1/demo-v1.3.1.fw" } ] } ] }
  ]
}
```

### ③ 单个对象

直接给一个 `{ "name": "...", "url": "...", ... }` 也认（`name` 缺省会用 `file` 字段）。

字段说明：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `name` / `file` | 是 | 文件名（必须以 `.fw` 结尾才会被收下） |
| `url` | 否 | 相对清单的路径；不填就用文件名 |
| `version` | 建议 | 用于排序显示，`v1.3.1` 和 `1.3.1` 都认 |
| `size` | 否 | 给了解析时会核对长度 |
| `crc32` | 否 | 给了会核对整包 CRC32（支持 `"9A3C1F08"` 字符串或十进制数） |
| `payload_crc32` | 否 | 仅供显示 |
| `board` | 否 | 板卡名，列在明细里供人确认 |

## 4. 列表怎么排序、怎么过滤

- **只收 `.fw`**（大小写不敏感）；
- 按版本号**从新到旧**排序：版本号先转成 u32（`ver_u32`）再比，`1.10.0 > 1.9.0` 这类不会比错；
- 清单里所有 `.fw` 都会列出来，**板卡名只作展示**，用哪个由人决定
  （早期版本按固定板名过滤，换个项目就得改代码，开源版去掉了这个耦合）。

## 5. 下载后的自检（`download_fw`）

按顺序卡四道，任何一道不过都不会把包发上设备：

1. `parse_fw` 解析包头（magic / 两处 CRC / 长度）；
2. 版本号必须是**三段式**；四段式老包直接报"设备现在的规则会拒收，请换新包"；
3. 清单里的 `size` 和实际下载长度一致（防截断）；
4. 清单里的 `crc32` 和整包 CRC32 一致（防内容被替换）。

## 6. 使用步骤

1. 升级页 → 来源选「服务器」；
2. 地址栏填目录或 manifest 地址（填过就记住）；
3. 点「读版本」，列表会显示版本/大小/CRC/板卡名；
4. 选一个版本，选「串口」或「网口」通道，点开始升级 —— 后续流程见
   [02](02-固件升级-串口在线升级.md) / [03](03-固件升级-网口服务通道.md)；
5. 上位机会把"读版本失败/CRC 不对/版本太旧"这类原因直接打在日志里。

## 7. 注意

- 服务器**不需要**任何鉴权字段，若要走企业网关自行加反向代理即可；
- 建议清单里同时给 `size` 和 `crc32`，这样"包被换过"能第一时间发现；
- 上线新固件时**同时更新 manifest.json**，否则列表里看不到新版本。
